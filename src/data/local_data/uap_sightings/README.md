# UAP sighting reports (bundled snapshot)

Stratified geocoded *sighting reports* derived from the NUFORC-derived
compilation published by Sigmond Axel on Zenodo:

- DOI: https://doi.org/10.5281/zenodo.1205624
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)

## Contents

- `sightings.geojsonl` — Feature-per-line GeoJSON points with place, shape,
  time, short summary, and explicit `verified: false` labeling.

## Important labeling

These are **sighting reports, not verified phenomena**. The layer UI and
selection cards state that clearly. This pack is a bounded historical subset
for visualization; it is not a live NUFORC feed and does not scrape nuforc.org
(NUFORC site terms restrict other uses).
